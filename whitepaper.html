1. Introduction

LiLGcoin (LGX or ₲) is a peer-to-peer cryptocurrency and open-source software project. LiLGcoin is the first crypto by a musician. LiLGcoin was inspired by Bitcoin, Dogecoin, Ethereum and Tron. It shares many similarities with Wrapped Bitcoin and is based on Wrapped Bitcoin's original source code. LiLGcoin was designed to be used for cheaper transactions and to be more efficient for everyday use.

2. Blockchain

The LiLGcoin blockchain is capable of handling higher transaction volume than its counterpart - Bitcoin. Due to more frequent block generation [1], the network supports more transactions without a need to modify the software in the future. As a result, merchants get faster confirmation times, while still having the ability to wait for more confirmations when selling bigger ticket items.

3. Transaction Speed Time

On the Ethereum blockchain's faster average block time — about 15 seconds vs 10 minutes respectively [2] — increases the speed with which LGX can be transacted, compared to Bitcoin.

4. LiLGcoin Wallet/ Card

LiLGcoin plans to be the first crypto to offer a specific cold wallet made for LGX and your other crypto assets. Also, LGX debit/ credit card for spending in the future.

5. LGX Crypto Exchange

In the near future, we plan on creating the LGX Crypto Exchange where merchants can swap LiLGcoin for other DeFi projects and LGX Rare Gems [3] possibly worth 10-1000x more than LiLGcoin itself.

6. LGX Gaming

With the possibilities of gaming in the future, we will create a game where merchants can earn LiLGcoin by doing daily tasks and playing casino games [4].

7. Liquidity

Using eligible exchanges merchants will be able to earn yields from LiLGcoin transaction fees by becoming a liquidity provider [5] using whichever DeFi project they like.

8. LiLGcoin Network Security

LGX tokens are secured by the parent blockchain they run on — Ethereum/Binance. In turn, BNB is protected by the Ethash proof-of-work function, a representative of the Keccak family of hash functions.
